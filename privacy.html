LaraCal Privacy Policy

Last updated: October 9, 2026

LaraCal is a personal, self-hosted application used only by its owner to display upcoming calendar events on a home e-ink screen.

Data accessed

With your permission, LaraCal requests read-only access to Google Calendar events (calendar.events.readonly). It reads event titles, times, and locations to show the next events on the display.

How data is used and stored

  • Calendar data is used only to render the display.
  • Data and the OAuth refresh token are stored only on the owner's private home server.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.

Google API Services User Data Policy

LaraCal's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke access at any time at myaccount.google.com/permissions.
